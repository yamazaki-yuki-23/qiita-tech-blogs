# リストアの方法

```
psql -U ユーザー名 -h ホスト名 -p ポート リストア先のDB < リストアするファイル
```

__注意__
* リストアするときは、リストアするファイルはフルパスか指定か、もしくはファイルのあるディレクトリに移動してファイル名のみ指定して実行する。
