#時間の正体
![スクリーンショット 2021-01-30 19.37.14.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/554111/faaf9441-ac6e-f76b-5cb2-8910a1b0705d.png)

画面左上の時間は、レンダリングに掛かった時間を意味しています。
表示したい場合、`rack-mini-profiler`というgemをインストールする必要があります。非表示にしたければ、`Gemfile`にてインストールの箇所をコメントアウトすれば大丈夫です。

#rack-mini-profilerインストール

```
gem 'rack-mini-profiler'
```
※Railsのバージョンによっては、デフォルトでGemfileにrack-mini-profilerが導入されています。

導入すると`Gemfile`に開発環境グループで追加されます。

```:Gemfile
group :development do
  // 省略
  gem 'rack-mini-profiler', '~> 2.0'
  // 省略
end
```

もし環境によって適用を変更したい場合は、こちらの記事を参考になります。
[Railsのパフォーマンス調査でrack-mini-profilerを使ってみました](https://techblog.gmo-ap.jp/2020/06/08/rack-mini-profiler/)
