#はじめに
業務で調べる機会があったので備忘録としてまとめました。

#取得方法
実行中の関数は`__FUNCTION__`という定数に格納してある。


```
public function test() {
 echo __FUNCTION__;
}
```
出力結果

```
test
```

#おまけ
`__FUNCTION__`のような使用する場所によって値が変化する定数（マジカル定数）は、[PHP公式][link]によれば9つ存在する。
[link]:(https://www.php.net/manual/ja/language.constants.predefined.php)
